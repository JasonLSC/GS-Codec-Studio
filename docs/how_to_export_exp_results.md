# How to Organize and Export Experiment Data

In this document, we cover: 1) how to obtain aggregated experiment data, and 2) how to create RD curves/tables.

## Experiment Data Aggregation
Assuming you have successfully run our experiment scripts (e.g., [train_multi_ratepoint.sh](examples/scripts/static_exps/tt/train_multi_ratepoint.sh)) and completed the experiments, you will obtain an experiment directory containing multiple bitrates/scenes (e.g., results/tt_mcmc_comp_sim). Next, you can use the aggregation script [summarize_rd_from_exps.py](tools/summarize_rd_from_exps.py) to consolidate the experiments in that directory and export a JSON file with detailed experiment data.

You need to provide two key arguments: 1) the experiment directory path and 2) the aggregated data file (JSON file). Example usage is shown below:

``` bash
# Basic usage - process experiment directory
python tools/summarize_rd_from_exps.py results/tt_mcmc_comp_sim

# Specify custom output file
python tools/summarize_rd_from_exps.py results/tt_mcmc_comp_sim -o my_summary.json

# Process different experiment
python tools/summarize_rd_from_exps.py results/another_experiment -o results.json
```

The aggregated JSON file has the following structure:
```json
{
  "experiment_name": {
    "rd_0.1": {
      "train": {
        "PSNR": 20.59,
        "SSIM": 0.717,
        "LPIPS": 0.345,
        "Mem.(MB)": 4.68
      },
      "truck": {
        "PSNR": 23.82,
        "SSIM": 0.805,
        "LPIPS": 0.274,
        "Mem.(MB)": 4.59
      },
      "Average": {
        "PSNR": 22.21,
        "SSIM": 0.761,
        "LPIPS": 0.309,
        "Mem.(MB)": 4.64
      }
    }
  }
}
```

## RD Curve/Table Generation

In general, we plot the RD curves/tables based on the aggregated data of each baseline (for example, [static_rd.json](open_stats/static_rd.json)).

We also support merging the newly aggregated experiment data into the existing statistics file so that the performance of the new experiment can be visualized in the RD curve/table.

### Adding Experiment Data
Use `tools/merge_results.py` to merge the aggregated experiment summary into the consolidated statistics JSON that powers the static benchmarks. The script expects the JSON generated by `tools/summarize_rd_from_exps.py`, and it updates or creates the target method entry under the specified dataset. Key arguments include:
- `input_json`: path to the experiment summary that contains the `rd_*` variants.
- `--dataset`: dataset section to update inside the statistics JSON.
- `--method_name`: name of the method entry to overwrite or create (default: `new`).
- `--existing_data` / `--output_json`: input stats file to read and the destination file to write.
- `--variant_prefix`, `--dry_run`: optional controls for naming rate points and previewing changes.

```bash
# Merge new experiment statistics into a fresh snapshot
python tools/merge_results.py my_results.json \
       --dataset Tanks_and_Temples \
       --existing_data open_stats/static_rd.json \
       --output_json open_stats/new_static_rd.json

# Preview updates for a custom method name without writing files
python tools/merge_results.py my_results.json \
       --dataset Tanks_and_Temples \
       --method_name Ours \
       --dry_run
```

### RD Curve Generation
`tools/static_bench/make_rd_curve.py` renders rate–distortion curves from the consolidated statistics. It builds a grid of subplots where rows correspond to datasets and columns correspond to the selected metrics. Important options:
- `--data`: path to the statistics JSON (defaults to `tools/static_bench/static_rd.json`).
- `--metrics`: ordered list of metrics to plot (subset of `psnr`, `ssim`, `lpips`).
- `--out` / `--dpi`: output PNG path and figure resolution.
- `--show`: display the figure interactively instead of saving it.

```bash
# Plot PSNR and SSIM curves from a custom stats file at higher resolution
python tools/static_bench/make_rd_curve.py \
       --data open_stats/new_static_rd.json \
       --metrics psnr ssim \
       --out outputs/rd_curves_custom.png \
       --dpi 300

# Inspect the figure interactively without creating any file
python tools/static_bench/make_rd_curve.py --show
```

```bash
# Generate default figure into tools/static_bench/static_rd_curves.png
python tools/static_bench/make_rd_curve.py

# Custom metrics and output location
python tools/static_bench/make_rd_curve.py --metrics psnr lpips \
       --out outputs/tt_rd_curves.png

# Show interactively without saving
python tools/static_bench/make_rd_curve.py --show
```

### RD Table Generation
`tools/static_bench/make_rd_table.py` converts the static benchmark statistics into a LaTeX table (and optionally a PDF). It normalises dataset labels, merges variants across datasets, and highlights the top-ranked entries per metric. Core parameters:
- `--input`: statistics JSON to read (default `open_stats/static_rd.json`).
- `--output`: destination `.tex` file for the generated table.
- `--pdf`: optional PDF output path if you want the script to compile LaTeX automatically.

```bash
# Export a LaTeX table from the merged statistics
python tools/static_bench/make_rd_table.py \
       --input open_stats/new_static_rd.json \
       --output outputs/static_rd_table.tex

# Generate the table and compile it into a PDF in one step
python tools/static_bench/make_rd_table.py \
       --input open_stats/new_static_rd.json \
       --pdf outputs/static_rd_table.pdf
```
